#  A MACHINE LEARNING APPROACH FOR IDENTIFYING FAKE SOCAIL MEDIA PROFILES

## About the Project

Developed a machine learning system to identify fake and genuine social media profiles using profile-related data. The system uses an Artificial Neural Network (ANN) model and a Django web application to classify profiles.

## Key Features

* Developed a machine learning system to identify fake and genuine social media profiles.
* Applied data preprocessing and feature extraction techniques to prepare profile data for classification.
* Implemented an Artificial Neural Network (ANN) model to classify profiles as fake or genuine.
* Integrated the trained model with a Django web application to provide a user interface for profile prediction.

## Technologies Used

Python, Pandas, Scikit-learn, TensorFlow/Keras, Artificial Neural Network (ANN), Django, HTML, CSS, and SQLite.

## Run the Project Locally

1. Open the project folder in VS Code.

2. Activate your Python virtual environment.

3. Install the required dependencies.

4. Start the Django development server:

   ```bash
   python manage.py runserver
   ```

5. Open the local server URL in your browser:

   `http://127.0.0.1:8000/`

6. Add `index.html` to the URL to access the application's page:

   `http://127.0.0.1:8000/index.html`

**Note:** Keep the Django development server running while using the application. The local URL is accessible only on your computer.
